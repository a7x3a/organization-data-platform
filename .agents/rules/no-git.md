# STRICT RULE: NO GIT COMMANDS

1. **NEVER execute any Git commands**:
   - Do NOT run `git push`, `git commit`, `git add`, `git pull`, `git checkout`, `git merge`, `git rebase`, `git reset`, `git stash`, or any other `git` command under any circumstances.
2. **Git is managed strictly manually by the USER**:
   - Leave all version control operations, committing, and pushing entirely for the user to perform manually in their shell.
